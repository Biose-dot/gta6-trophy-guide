An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a six-stage roadmap to the platinum, the one missable trophy clearly flagged, and a checklist saved in the browser with search, filters by kind, a spoiler mode, and export/import of progress. No build step, no network requests at run time — just static files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or serve `app/` with any static file server and open `app/index.html`.
